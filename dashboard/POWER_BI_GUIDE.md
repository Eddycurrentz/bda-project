# Power BI Dashboard — Setup Guide

This guide builds a **Real-Time Social Media Sentiment Dashboard** in Power BI
Desktop from the CSV output produced by `spark_stream.py`.

---

## 1. Connect to Data

1. Open **Power BI Desktop**.
2. **Home → Get Data → Folder**.
3. Browse to `SocialMediaSentiment/output/sentiment_stream/` and select it.
4. Click **Combine & Transform Data** — Power BI will merge every CSV
   part-file written by the Spark job into a single table.
5. In Power Query Editor, verify column types:
   - `timestamp` → Date/Time
   - `polarity`, `subjectivity`, `confidence` → Decimal Number
   - `sentiment` → Text
   - `tweet`, `clean_tweet` → Text
6. Click **Close & Apply**.

> Tip: For a quick one-off load instead of a folder query, use
> **Get Data → Text/CSV** and point directly at
> `output/sentiment_results.csv`.

---

## 2. Enable Refresh (Near Real-Time)

- **Home → Refresh** manually while the pipeline runs, or
- **File → Options → Data Load** to set **Refresh every N minutes** for
  automatic polling of the output folder (Power BI Desktop) — for a fully
  automated production refresh, publish to the Power BI Service and
  configure a **Scheduled Refresh** / **Gateway** against the output folder.

---

## 3. Data Model — Calculated Columns & Measures

Add these DAX measures (**Modeling → New Measure**):

```DAX
Positive Tweets = CALCULATE(COUNTROWS(sentiment_stream), sentiment_stream[sentiment] = "Positive")

Negative Tweets = CALCULATE(COUNTROWS(sentiment_stream), sentiment_stream[sentiment] = "Negative")

Neutral Tweets = CALCULATE(COUNTROWS(sentiment_stream), sentiment_stream[sentiment] = "Neutral")

Total Tweets = COUNTROWS(sentiment_stream)

Average Polarity = AVERAGE(sentiment_stream[polarity])

Average Subjectivity = AVERAGE(sentiment_stream[subjectivity])

Positive % = DIVIDE([Positive Tweets], [Total Tweets], 0)

Negative % = DIVIDE([Negative Tweets], [Total Tweets], 0)
```

## 4. Visuals to Build

### KPI Cards (top row)
Add 5 **Card** visuals:
1. `[Positive Tweets]`
2. `[Negative Tweets]`
3. `[Neutral Tweets]`
4. `[Average Polarity]`
5. `[Average Subjectivity]`

### Pie Chart — Sentiment Share
- Visual: **Pie Chart**
- Legend: `sentiment`
- Values: `Total Tweets`
- Apply conditional colors: Positive = green, Neutral = grey, Negative = red

### Bar Chart — Sentiment Count
- Visual: **Clustered Bar/Column Chart**
- Axis: `sentiment`
- Values: `Total Tweets`

### Line Chart — Sentiment Over Time
- Visual: **Line Chart**
- Axis: `timestamp` (set to Continuous, grouped by minute/hour)
- Values: `Total Tweets`, split by `sentiment` (Legend)
- Optionally add a second line chart for `Average Polarity` over `timestamp`

### Word Frequency
- Option A (native): **Word Cloud** custom visual (import from AppSource)
  bound to `clean_tweet`.
- Option B (static): Import `output/visualizations/word_frequency.png`
  generated by `visualize.py` as an **Image** visual.

### Table — Live Tweet Feed
- Visual: **Table**
- Columns: `timestamp`, `tweet`, `sentiment`, `polarity`, `confidence`
- Sort descending by `timestamp` for a "live feed" feel.

---

## 5. Filters / Slicers

Add three **Slicer** visuals to the report canvas:

1. **Date** — slicer bound to `timestamp` (Between / Relative Date filtering)
2. **Sentiment** — slicer bound to `sentiment` (Positive / Neutral / Negative)
3. **Keyword** — a text-search slicer bound to `clean_tweet`
   (**Format → Slicer settings → Style → List**, enable **Search**)
